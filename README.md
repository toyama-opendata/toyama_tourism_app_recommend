# とやま、わたし旅。

富山県観光ウェブアンケートの集計値と希望する体験から旅先を探すウェブアプリです。
試験公開版。富山県や観光施設の公式アプリではありません。

## GitHub Pagesで公開
このフォルダーのファイルをリポジトリのmainブランチ直下に配置します。
Settings → Pages → Deploy from a branch → main / (root) → Save。
公開URLはGitHub Pagesの設定画面で確認してください。
独自ドメインは不要です。

## 掲載情報と保存
基本情報は2026-10-29参照。料金・営業・運行の最新情報は施設公式をご確認ください。
アンケートの満足度は旅行全体の評価で、地点の評価や満足確率ではありません。
「気になる場所」はブラウザー内に保存します。端末間の同期はありません。
詳細な出典・情報の制限はsources.htmlをご覧ください。

## 素材
提供写真・集計データなどを含みます。このリポジトリの公開は、素材の自由な再利用を許諾するものではありません。


## 秋冬の季節補正
基本集計（2026年4〜8月、県外6,466件）は維持します。
`data.js` の `seasonHistory` は2025年4月〜2026年3月の県外5,190件を別集計したものです。秋は2025年9〜11月725件、冬は2025年12月〜2026年2月1,630件。季節は回答年月であり、実訪問日の判定ではありません。

旧調査票にも存在する21地点のみを対象にし、新設26地点・10件未満の季節セルは `null`（補正なし）です。原データの個票・自由記述は配信しません。

同じ旧調査票内の年間訪問割合 p = B / N を基準に、季節別割合を100回答分の事前情報で平滑化します。比率 R = ((b + 100p) / (n + 100)) / p を0.5〜2に制限し、内部スコアに `0.2 * log(R)` を加えます。係数は補助的な影響に制限する設計値で、予測精度を学習・検証した値ではありません。体験の一致数と体験カバーの優先順位は維持します。

前年の満足度・同行者等は2026年の集計に混ぜません。既存の季節除外は維持しますが、全施設の営業期間や交通の確認機能ではありません。
